# Cat Server Launcher

Простой и красивый лаунчер для Minecraft сервера на базе Forge 1.20.1 с авто-скачиванием модов.

## Как собрать лаунчер в .exe:
1. Установите Python (https://www.python.org/downloads/)
2. Запустите `build.bat`
3. Готовый лаунчер появится в папке `dist/CatLauncher/CatLauncher.exe`

## Настройка
Вы можете изменить ключ доступа и список модов в файле `config.py`.
